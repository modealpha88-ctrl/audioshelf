# AudioShelf Open Audiobook Provider Repository

This is a **native AudioShelf repository**, not a Tachiyomi extension repository.
It uses version-1 JSON manifests supported by AudioShelf v0.3+.

## Add to AudioShelf

1. Open **AudioShelf → Sources**.
2. Paste the following **Repository URL** into the *Repository URL* field (not the *Audiobook page URL* field):

   `https://raw.githubusercontent.com/modealpha88-ctrl/audioshelf/main/sources/manifest.json`

3. Tap **Add repository**.
4. Install the providers you want.
5. Switch to **Browse** and select the installed source or **All sources**.

## Providers

**Mistborn is not a public-domain audiobook.** Its entries are external listening links, not free full-book downloads. Use the Open official provider button in AudioShelf v0.4.2+ to access licensed retail purchases, authorized previews, or library loans. Availability varies by country and library.


| Provider | Audio rights / description | Format |
| --- | --- | --- |
| Open Audiobooks | Original recordings under CC0, based on public-domain Standard Ebooks editions | One M4B per title (includes embedded chapters) |
| Loyal Books | Public-domain audiobook catalogue based mainly on LibriVox | MP3 chapters from RSS enclosures |
| Project Gutenberg Open Audiobooks | Project Gutenberg / Microsoft / MIT free-access collection (verify individual text copyright by country) | Audio RSS enclosures |
| Mistborn — Official Editions | Licensed Brandon Sanderson audiobooks, opening authorized providers via external URLs | Official links to Libby/OverDrive, Google Play, and GraphicAudio (not in-app audio) |

Catalogue JSON files are generated by [the refresh script](../scripts/update_audiobook_catalogs.py),
validated by [the schema checker](../scripts/validate_audiobook_catalogs.py),
and refreshed weekly by [GitHub Actions](../.github/workflows/update-audiobook-sources.yml).

**Limitations:** These are a sample of the remote catalogues, not a full index. The browse JSON
currently has a maximum of 60 books per provider; search filters the loaded browse list rather
than querying the complete sites. Open Audiobooks M4B appears in AudioShelf as one audio item;
the app's chapter UI does not yet expose embedded M4B chapter markers. A failed source fetch
never silently clears an existing valid catalogue. Empty provider catalogues may remain
until a successful refresh.

The source websites may change URLs or access rules. The media streams are hosted by their
original providers, not AudioShelf. Do not try to bypass access controls or redistribute
materials without checking rights. Audiobook/public-domain status may depend on jurisdiction.

This repository does not package third-party APKs, executable extensions or torrents.
