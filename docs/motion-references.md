# Motion references

Use these upstream projects to explore interaction patterns and build web prototypes for AudioShelf. Implement Android interactions with Jetpack Compose and check them on a device.

| Repository | Reference for | Agent skill source |
| --- | --- | --- |
| [GSAP](https://github.com/greensock/GSAP) | Timelines, easing, staggered entrances, and shared-element motion | [Official GSAP skill pack](https://github.com/greensock/gsap-skills) |
| [Lenis](https://github.com/darkroomengineering/lenis) | Smooth scrolling and scroll-linked effects | [Darkroom's Lenis setup skill](https://github.com/darkroomengineering/cc-settings/blob/f127235%5E/skills/lenis/SKILL.md) |
| [React Bits](https://github.com/DavidHDev/react-bits) | Animated components, text effects, and backgrounds | [Community React Bits skill](https://github.com/Philotheephilix/reactbits.dev-skill) |
